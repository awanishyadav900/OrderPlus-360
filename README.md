# OrderPlus-360

## Overview

This Power BI dashboard provides a comprehensive analysis of customer behaviour, sales performance, and business insights.

The dashboard helps identify

✔ Customer Segmentation

✔ Sales Performance

✔ Revenue Trends

✔ Top Customers

✔ Profit Analysis

✔ Regional Performance
